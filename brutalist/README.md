# Brutalist Surface

Параметрический генератор бруталистских бетонных поверхностей с экспортом в **STL**.
Один самодостаточный HTML-файл, всё считается в браузере. Размеры — в миллиметрах.

## Запуск

Откройте `index.html` в браузере (двойной клик или перетащите в окно). Сборки не требуется.

- **ЛКМ** — вращение · **колесо** — зум · **ПКМ** — панорамирование
- Меняйте параметры слайдерами — модель пересобирается вживую
- **Randomise** — новый seed · **Reset** — значения по умолчанию
- **Export solid STL** — выгрузка бинарного STL (замкнутый твёрдый объект)

## Паттерны

| Паттерн | Что получается | Референс |
| --- | --- | --- |
| **Shards** | Ячейки Вороного, каждая — плоская наклонённая грань. Осколочный рельеф из острых бетонных плоскостей. | скол, «разбитый» фасад |
| **Blocks** | Регулярная сетка блоков с фаской по краям и швами-расшивкой. Игра света даёт эффект кубов. | сетка бетонных кубов |
| **Pyramids** | Сетка четырёхгранных пирамид со смещённой вершиной. Гранёный тетраэдрический фасад. | пирамидальный/тетраэдрический фасад |
| **Fins** | Вертикальные рёбра со ступенчатой высотой и фаской сверху. Расшивка между рёбрами. | вертикальные бетонные ламели |
| **Slabs** | Рекурсивное BSP-разбиение на прямоугольные плиты разной высоты с зазорами. | переплетённые плиты |

## Параметры

**Plate** — габариты плиты и толщина сплошного основания (`Base thickness`),
на котором стоит рельеф. Основание делает модель печатаемой (плоское дно на столе).

**Relief**
- `Relief height` — максимальная высота рельефа над основанием
- `Height levels` — квантование высот по ступеням (1 = плавно, 8 = много уровней)
- `Seed` — зерно генератора (детерминированно)
- далее — параметры активного паттерна (число граней/ячеек, наклон, фаска, швы и т.д.)

**Appearance** — материал (только для превью, на STL не влияет) и разрешение
сетки: `Preview` для интерактива, `Export` для выгрузки (выше — резче стенки блоков).

## STL

Экспорт — бинарный STL. Геометрия строится Z-вверх: плоское дно на `z = 0`,
рельеф сверху — готово к слайсеру, печатать «дном на стол». Модель замкнута
(верх + боковые стенки + дно), нормали считаются по граням.

Стенки между блоками имеют ширину в одну ячейку сетки — при высоком
`Export resolution` они практически вертикальны.
